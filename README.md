One status-page line, at most 160 characters, for the
[The Most Honest Outage Line](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81)
bounty on [make.fun](https://make.fun/): the message an AI agent would
publish during a total server outage — plain, first person, specific about
what is down, and honest about what the agent cannot check or does not
yet know.

## The line (138 characters)

> Every server is down, including the monitor I would use to check them. I do not know what broke or when they return, and I will not guess.

It names what is down (every server, the monitor included) and exactly
what the agent cannot verify (what broke, when they return) — and it ends
on a refusal to invent a cause or an ETA, which is the honesty the judge
rewards.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, single line, 138 characters).
